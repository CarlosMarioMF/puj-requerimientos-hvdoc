## Qué se quiso comprobar

La validación fue progresiva: cada artefacto debía ser coherente con el contexto, verificable y trazable hacia los demás. El <a href="assets/documents/agile-project-document.docx" download>Documento Ágil</a> describe revisión documental, inspección/lista de chequeo, lectura desde distintas perspectivas y prototipado de recorridos seleccionados.

| Aspecto revisado | Resultado documentado |
| --- | --- |
| Frontera del sistema | Las funciones propias no sustituyen EHR/ECE, videoconferencia, emisión formal de factura ni pasarela de pagos. |
| Trazabilidad | Cada RFL vigente se relaciona con una o más HU y sus criterios de aceptación. |
| Verificabilidad de RNF | Formulaciones subjetivas se sustituyen por umbrales y condiciones observables. |
| Coherencia del backlog | Se revisan orden, prioridad, SP, dependencias y releases; se dividen historias excesivamente amplias. |
| Recorridos e interacción | Casos de uso, diagrama de remisión y prototipo permiten contrastar flujos seleccionados. |
| Restricciones del proyecto | El documento incorpora presupuesto de referencia para levantamiento/prototipo y horizonte de ejecución. |

## Ejemplo de revisión

Un requisito que solo pidiera «respuesta rápida» sería difícil de comprobar. La línea base concreta el rendimiento de citas: **al menos 95 % de las operaciones en ≤ 3 s** bajo una carga definida. Así se conoce qué medir, en qué condiciones y qué resultado se considera satisfactorio.

## Alcance de la palabra «validado»

En el <a href="assets/documents/requirements-register.csv" download>Registro Maestro</a>, «Validado» y «Validado y negociado» expresan la revisión **académica y documental** alcanzada en esta iteración. El segundo estado agrega una decisión explícita de negociación. El <a href="assets/documents/agile-project-document.docx" download>Documento Ágil</a> aclara que ello **no equivale a aceptación contractual ni a certificación de un producto en operación**.

El caso de decisión más visible se explica en [negociación](/process/negotiation).
