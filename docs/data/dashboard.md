## Cómo interpretar el panel

Un **requisito** es una obligación documentada en la línea base; una **historia de usuario** es una unidad de planificación; un **punto de historia** expresa esfuerzo relativo; un **evento de cambio** registra una decisión histórica. Las cuatro cifras tienen denominadores diferentes. Los requisitos RNF y RPY se muestran como *Transversal* cuando el registro no les asigna una entrega concreta. La prioridad *N/A* significa que no recibieron prioridad MoSCoW individual.

Las barras muestran recuentos, acompañados por su valor numérico. Use el [explorador de requisitos](/data/requirements) para examinar los 83 registros y el [explorador de cambios](/data/changes) para revisar los 15 eventos. La [clasificación y especificación](/process/specification), la [priorización](/process/prioritization) y la [gestión de cambios](/process/management) explican el método detrás de estas cifras.
