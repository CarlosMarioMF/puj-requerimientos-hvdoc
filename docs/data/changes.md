## Lectura metodológica

El historial conserva las decisiones de consolidación, reclasificación, separación, retiro y creación. El [Registro Maestro](/data/requirements) describe el estado vigente; la [gestión de requisitos](/process/management) explica cómo se actualizó la línea base. Los identificadores históricos del log pueden no figurar como filas vigentes.
