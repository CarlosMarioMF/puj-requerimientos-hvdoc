# Ingeniería de requisitos del Hospital Virtual Universitario

Esta documentación presenta **cómo se obtuvieron, especificaron, priorizaron, validaron, negociaron y gestionaron** los requisitos del Sistema de Apoyo para la Gestión de Actividades Médicas de un Hospital Virtual Universitario.

> **Documento rector:** <a href="assets/documents/agile-project-document.docx" download>Documento Ágil del Hospital Virtual</a>, versión 0.4, 19 de octubre de 2026. La <a href="assets/documents/requirements-specification.docx" download>Especificación de Requisitos</a> y el <a href="assets/documents/user-stories-product-backlog.docx" download>Product Backlog</a> amplían el detalle; el <a href="assets/documents/requirements-register.csv" download>Registro Maestro de Requisitos</a> y el <a href="assets/documents/requirements-change-log.csv" download>Historial de Cambios</a> conservan los datos estructurados.

## La idea central

El producto propuesto coordina atención virtual, actividad clínica, formación universitaria y operación administrativa. Su frontera deja la historia clínica electrónica institucional, la videoconferencia, la facturación formal y el procesamiento de pagos en los sistemas especializados correspondientes.

Los puntos de historia expresan esfuerzo relativo, no horas ni dinero. La [página de fuentes y método](/sources) reúne los archivos y precisa la interpretación de la evidencia.
